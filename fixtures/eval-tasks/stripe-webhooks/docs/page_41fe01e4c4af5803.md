This is an object representing your Stripe balance. You can retrieve it to see the balance currently on your Stripe account.

The top-level `available` and `pending` comprise your “payments balance.”

Related guide: [Balances and settlement time](/payments/balances), [Understanding Connect account balances](/connect/account-balances)

# [Retrieve balance](/api/balance/balance_retrieve)

Copy for LLM

GET /v1/balance

Retrieves the current account balance, based on the authentication that was used to make the request. For a sample request, see [Accounting for negative balances](/connect/account-balances#accounting-for-negative-balances).

### Parameters

No parameters.

### Returns

Returns a balance object for the account that was authenticated in the request.

```
curl https://api.stripe.com/v1/balance \  -u "sk_test_tR3PYbc...96tH88S4VQ2usk_test_tR3PYbcVNZZ796tH88S4VQ2u:"
```

Response

```
{  "object": "balance",  "available": [    {      "amount": 666670,      "currency": "usd",      "source_types": {        "card": 666670      }    }  ],  "connect_reserved": [    {      "amount": 0,      "currency": "usd"    }  ],  "livemode": false,  "pending": [    {      "amount": 61414,      "currency": "usd",      "source_types": {        "card": 61414      }    }  ]}
```

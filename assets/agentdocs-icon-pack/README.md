# AgentDocs Icon Pack

Suggested usage:

| File | Use |
|---|---|
| `hero-agentdocs.png` | Homepage hero, README top visual, social preview base |
| `feature-build.png` | `agentdocs build`, compile docs, structured outputs |
| `feature-search.png` | Search, SQLite/FTS5 index, retrieval |
| `feature-audit-evidence.png` | Audit trail, evidence-linked outputs, traceability |
| `feature-task-packs.png` | Task packs, workflows, guided agent steps |
| `feature-mcp-tools.png` | MCP tools, integrations, read-only tool access |
| `feature-doctor-readiness.png` | `agentdocs doctor`, readiness reports, diagnostics |
| `feature-local-first-safe.png` | Local-first processing, safety, privacy, no execution |

Recommended repo path:

```txt
docs/public/brand/
```

Example usage for GitHub Pages under `/AgentDocs/`:

```tsx
<img
  src="/AgentDocs/brand/feature-search.png"
  alt="Search indexed documentation"
  className="feature-illustration"
/>
```

These are best used as feature illustrations at roughly 320–480px wide, not as tiny nav icons or favicons.

CLI Reference

The AgentDocs command-line interface (CLI) is the primary engine for generating, validating, and serving AI-native documentation. Use this reference to master the deterministic logic behind your documentation build pipelines.

build

bolt

Compiles raw markdown and YAML manifests into an optimized JSON schema ready for LLM consumption. This process includes semantic validation and cross-reference linking.

Usage: agent-docs build [options] 
$ agent-docs build --src ./docs --out ./dist --minify
[INFO] Found 42 source files...
[INFO] Resolving context gates...
[PASS] Build successful in 420ms
FLAG DESCRIPTION DEFAULT
--src, -s Path to the documentation source directory. ./docs
--out, -o Output directory for compiled artifacts. ./dist
--minify Compress JSON output for production use. false

doctor

health_and_safety

Performs a deep diagnostic audit of your project configuration, node environment, and documentation structure to ensure maximum compatibility with the AgentDocs core engine.

Usage: agent-docs doctor 
$ agent-docs doctor
✔ Node.js v20.x detected
✔ Config file found
! Warning: 3 broken links in /reference
✔ LLM Gateway reachable

serve-mcp

hub

Starts a Model Context Protocol (MCP) server that exposes your documentation as a set of dynamic tools and resources for LLM agents like Claude Desktop.

Usage: agent-docs serve-mcp [options] 
$ agent-docs serve-mcp --port 3000 --watch
[MCP] Server started at localhost:3000
[MCP] Tools registered: get_docs, search_reference
● Listening for agent requests...
FLAG DESCRIPTION DEFAULT
--port, -p Port to run the MCP server on. 3000
--watch, -w Restart server on documentation changes. false

verify-context

verified

Validates that your generated documentation follows the "Context Gate" rules, ensuring that AI models can efficiently parse and navigate the provided information.

Usage: agent-docs verify-context [file] 
$ agent-docs verify-context ./dist/schema.json

Context Verification Passed

Score: 98/100. All context gates are correctly structured.

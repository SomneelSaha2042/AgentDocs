Installation & Quick Start

Set up your mission-control for AI documentation logic. AgentDocs provides a rigorous, deterministic framework to ensure your automated agents always have the correct context.

01

5-Minute Quick Start

download 1. Install Global CLI

First, pull the core binaries. Requires Node.js 18+ or Python 3.10+.

Terminal — zsh 
npm install -g @agentdocs/core

settings_input_component 2. Initialize Workspace

Create your project manifest. This generates the agent.config.json used to manage context gates.

Terminal — bash 
agentdocs init --template=minimal
02

The Documentation Workflow

play_circle

Testing with 'agentdocs try'

The try command is your primary validation tool. It simulates an agent's traversal of your documentation without actually making API calls, allowing you to debug logical loops and dead ends in your technical manuals.

agentdocs try ./docs/auth-flow.md
PASS Context Gate 04: Resolved
WARN Latency: 240ms (High overhead)
warning Warning

Context Drift

Always run --fresh when testing documentation that involves real-time API schemas. Stale context results in non-deterministic agent behavior.

lightbulb
Pro-Tip

Atomic Context Mapping

Keep your documentation files under 1,500 words. Larger files cause context window saturation for agents, leading to hallucinations during technical execution. Use the "Gate Logic" to link smaller documents instead of one massive manual.
